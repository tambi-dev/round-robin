# Round Robin

Учебная реализация планирования CPU по алгоритму Round Robin на Python и браузерный калькулятор.

## Python

Запустите `python round_robin.py` или откройте файл в PyCharm и нажмите Run. Требуется Python 3, дополнительных библиотек нет.

Программа выводит диаграмму Ганта, Completion Time, Waiting Time, Turnaround Time и средние значения. Данные процессов и квант задаются в нижней части файла. Функция рассчитана на непустой список процессов с уникальными именами, целыми Arrival от 0 и положительными целыми Burst и квантом.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Сервер и установка зависимостей не нужны.

Введите квант времени, Arrival (время прихода) и Burst (длительность работы на CPU), затем нажмите «Рассчитать». Калькулятор построит диаграмму Ганта и покажет Waiting Time и Turnaround Time для каждого процесса и в среднем.

## Пример

| Процесс | Arrival | Burst |
| --- | ---: | ---: |
| P1 | 0 | 5 |
| P2 | 1 | 3 |
| P3 | 2 | 1 |
| P4 | 3 | 2 |

При кванте **2** среднее Waiting Time равно **4,5**, а среднее Turnaround Time равно **7,25**. Прибытия на границе кванта добавляются в очередь перед возвратом вытесненного процесса.
